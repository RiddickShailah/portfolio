# Shailah Riddick — Portfolio

Personal portfolio site showcasing projects from `~/Desktop/Projects`.

## Run locally

```bash
cd ~/Desktop/Projects/portfolio
python3 -m http.server 8080
```

Open **http://localhost:8080**

## Deploy to get a live URL

### Option A — Vercel (recommended)

1. Push this folder to GitHub as `RiddickShailah/portfolio` (or any repo name).
2. Go to [vercel.com/new](https://vercel.com/new) and import the repo.
3. Framework preset: **Other** (static site).
4. Deploy — you'll get a URL like `https://portfolio-riddickshailah.vercel.app`.

Or from the terminal:

```bash
cd ~/Desktop/Projects/portfolio
npx vercel
```

### Option B — GitHub Pages

1. Push to GitHub as `RiddickShailah/portfolio`.
2. In the repo: **Settings → Pages → Deploy from branch → main → / (root)**.
3. Your URL will be: **https://riddickshailah.github.io/portfolio/**

### Option C — Custom domain

Point a domain (e.g. `shailahriddick.dev`) to Vercel or GitHub Pages in your DNS settings.
